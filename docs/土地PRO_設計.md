# 土地診断のPRO版 ── 設計メモ

2026-09-16 時点の設計案。まだ何も実装していない。

---

## 0. 結論から

**土地のPROは、戸建・マンションのPROより価値を出しやすい。**

建売とマンションは、買う人が「完成したもの」を見られる。写真も見取図もある。
だからPROで足せるのは、見ても分からないこと（雨漏りの跡、設備の更新時期、
性能評価書）に限られる。

土地は違う。**買ったあとにかかるお金が、買う前には一つも見えない。**
しかも単位が百万円で、土地価格の1割に届くことがある。

| 見えない費用 | いつ判明するか |
|---|---|
| 地盤改良 | 地盤調査をするまで分からない（契約後が普通） |
| 上下水道・ガスの引き込み | 本管の位置を調べるまで分からない |
| 擁壁のやり替え | 検査済証を探すまで分からない |
| 古家の解体 | 見積りを取るまで分からない |
| つなぎ融資の利息 | 誰も教えてくれない |

無料版はここに一切触れていない（触れられない。公的データに無い）。
**PROの中身は、ここを一つずつ埋めることになる。**

## 1. 無料版でもう埋まっているもの（棚卸し）

先に確認した。公的データで取れるものは、無料版でほぼ取り切っている。

| 項目 | 出所 | 無料で見ている |
|---|---|---|
| 用途地域・建ぺい率・容積率 | XKT002 | ○ |
| 市街化区域／調整区域 | XKT001 | ○ |
| 洪水・土砂・津波・高潮 | XKT026〜029 | ○ |
| 液状化・盛土・急傾斜地・地すべり・災害危険区域 | XKT025/020/022/021/016 | ○ |
| 周辺施設・学区・将来人口 | XKT004〜018 | ○ |
| 近隣の土地成約（坪単価の分布・私道率・不整形率） | XIT001 | ○ |
| 前面道路による容積率の制限（法52条2項） | 計算 | ○ |
| セットバックの概算 | 計算 | ○ |

**つまりPROで足すものは、APIを増やしても出てこない。**
現地を見た人と、重要事項説明書・測量図・登記簿を持っている人にしか
答えられないことばかりになる。これは戸建PROと同じ構造で、良い兆候。

## 2. PROで聞く項目

戸建PROと同じ形（選択式・「未確認」を必ず用意し、未回答は減点せず充足度を下げる）
で設計する。

### A. 買ったあとに必ず出ていくお金（最重要）

| 項目 | 選択肢 | どこで分かるか |
|---|---|---|
| 上水道の引き込み | 引込済み（口径20mm以上）／引込済み（13mm）／前面道路に本管あり・未引込／本管なし／未確認 | 市区町村の水道課 |
| 下水道 | 公共下水に接続済み／前面道路に本管あり・未接続／浄化槽が要る／未確認 | 同上 |
| ガス | 都市ガス引込済み／前面道路に本管あり／プロパンのみ／未確認 | ガス事業者 |
| 地盤調査 | 実施済み・改良不要／実施済み・改良要／未実施／未確認 | 売主・仲介 |
| 擁壁 | なし／あり・検査済証あり／あり・検査済証なし／あり・不明 | 現地＋建築指導課 |
| 高低差 | ほぼ平坦／道路より高い／道路より低い／未確認 | 現地 |
| 古家 | なし／あり・解体費は売主負担／あり・買主負担／未確認 | 契約条件 |
| 残置物・工作物 | なし／あり／未確認 | 現地 |

**13mm口径をわざわざ選択肢に入れる理由**：2階建て以上で水回りが複数あると
20mmへの増径が要り、道路の掘削を伴う。引込済みでも安心できない典型。

**検査済証のない擁壁**は、建て替え時にやり替えを求められることがある。
「擁壁あり」で終わらせず、検査済証の有無まで聞く。

### B. 建てられる形を決める規制（無料では計算していない）

| 項目 | 選択肢 | 効かせ方 |
|---|---|---|
| 角地か | 角地（緩和あり）／角地でない／未確認 | 建ぺい率+10%を計算に反映 |
| 防火指定 | 防火地域／準防火地域／法22条区域／指定なし／未確認 | 建物コストの注意を出す |
| 高度地区 | 第一種／第二種／第三種／指定なし／未確認 | 絶対高さと北側斜線 |
| 地区計画・建築協定 | あり／なし／未確認 | あれば「外壁後退・高さ・意匠の制限を要確認」 |
| 風致地区・景観地区 | あり／なし／未確認 | 同上 |
| 真北方向 | 測量図から（度）／未確認 | 北側斜線の簡易計算 |

**角地緩和は即座に計算に乗る。** 建ぺい率60%→70%で、120㎡なら建築面積が
72㎡→84㎡。1階の広さが12㎡増える。無料版で出している数字が変わる。

**地区計画は「あり／なし」だけでも価値がある。** あるのに気づかず設計を
進めて、外壁後退1mで計画をやり直す例が実際にある。

### C. 買えるかどうか・いつ買えるか

| 項目 | 選択肢 | 根拠 |
|---|---|---|
| 地目 | 宅地／農地（田・畑）／雑種地／山林／未確認 | 登記簿 |
| 埋蔵文化財包蔵地 | 該当する／しない／未確認 | 市区町村の教育委員会 |
| 建築条件 | 条件なし／建築条件付き／未確認 | 広告・契約書 |
| 私道の掘削・通行承諾 | 書面あり／口頭のみ／なし／未確認（私道のときだけ聞く） | 売主・仲介 |
| 私道の持分 | あり／なし／未確認 | 登記簿 |
| 境界確定測量 | 確定済み・図面あり／未確定／未確認 | 測量図 |
| 越境 | なし／あり（塀・屋根・配管）／未確認 | 測量図・現地 |
| セットバックの実測 | 後退後の有効面積（㎡） | 測量図 |

**農地**は条文を引いて確認した（農地法・e-Gov）。

- 第4条第1項第7号／第5条第1項第6号 … **市街化区域**内の農地は、あらかじめ
  農業委員会に**届け出て**転用できる
- それ以外（市街化調整区域など）は**都道府県知事等の許可**が要る

つまり同じ「農地」でも、市街化区域なら届出で済み、調整区域なら許可が要る。
無料版は区域区分をすでに持っているので、**地目さえ聞けば、どちらの手続きに
なるかまで自動で出せる。**

**埋蔵文化財包蔵地**も条文で確認した（文化財保護法第93条）。周知の埋蔵文化財
包蔵地を土木工事のために発掘するときは、**着工の60日前まで**に届出が要る
（第92条第1項の「30日前」を「60日前」と読み替える、と条文にそう書いてある）。
試掘調査になると数か月止まることがあるので、着工時期を決める前に知りたい。

**建築条件付き**は、注文住宅を探している人にとって決定的。条件付きなら、
そもそも「注文住宅の土地」ではない。**これは無料版で聞いてもいいくらい重い**
（後述）。

### D. 資金 ── ここがPROの目玉になる

**つなぎ融資を、いまサイトのどこでも扱っていない。** 確認した（実装なし）。

注文住宅は、土地の決済が先で、建物の完成が半年〜1年後になる。その間、
住宅ローンは実行されない。だから土地代金を「つなぎ融資」で立て替える。

| 聞く項目 | 使い道 |
|---|---|
| 土地の決済予定日 | つなぎ期間の始点 |
| 建物の完成予定日 | つなぎ期間の終点 |
| つなぎ融資の金利 | 利息の計算（本融資より高いのが普通） |
| 着工金・中間金の割合 | 分割実行ごとの利息 |
| 付帯工事費・外構費の予算 | 総額を現実に近づける |
| 諸費用の予算 | 同上 |

これで**「いつ・いくら要るか」の時系列**が出せる。既にある
「詳細な資金計画」の土地版で、いちばん喜ばれるはず。

## 3. PROで新しく計算できるようになるもの

聞くだけで終わらせず、計算に乗せる。ここがPROの「精度が高い」の中身になる。

1. **角地緩和を反映した建築面積** … 建ぺい率+10%
2. **北側斜線の簡易判定** … 真北方向＋用途地域から、2階北側が削られるかを出す
   （低層住居専用なら 5m or 10m + 1.25 勾配）
3. **絶対高さ** … 第一種・第二種低層住居専用地域の10m/12m
4. **セットバック後の実面積** … 概算をやめ、測量図の実測に置き換える
5. **つなぎ融資の利息** … 決済日・完成日・金利・分割実行から
6. **総額の積み上げ** … 土地＋建物本体＋付帯＋外構＋諸費用＋地盤改良見込み
   → 返済負担率を現実の数字にする
7. **農地・埋蔵文化財の手続きと所要期間** … 着工までの逆算

## 4. 配点をどう扱うか

**配点は変えない。** 戸建PROと同じで、`pro_scoring.py` のやり方に合わせる
（カテゴリの weight は据え置き、CategoryScore の raw を上書きして充足度を上げる）。

理由は2つ。

- 無料とPROで配点が違うと、「無料82点 → PRO74点」の差が何なのか説明できなくなる
- いまの6カテゴリは、PROで聞く項目をちゃんと受け止められる

| カテゴリ | PROで深くなるもの |
|---|---|
| 建てられる家 25 | 角地緩和・斜線・絶対高さ・地区計画・セットバック実測 |
| 接道 15 | 掘削/通行承諾・私道持分・位置指定図面 |
| リスク 25 | 擁壁・地盤調査・高低差・越境・境界・埋蔵文化財 |
| 立地 15 | （変わらない。公的データで足りている） |
| 資産性 10 | 建築条件・地目・境界確定の有無 |
| 資金 10 | つなぎ融資・総額の積み上げ |

**点数と別に、一枚の資金計画を出す。** 費用の積み上げを点数に押し込むと
情報が潰れる。土地版の資金計画PDFを別に出すほうが、読む人の役に立つ。

## 5. 「無料の項目をPROに移すべきか」への答え

**移さないほうがいい。** 1つも。

理由は、いまの方針そのもの。「本質的にPROのほうが精度が高く、有益で良い
サービスだと思ってもらいたい」という作り方をしている。無料を削って差を
つくると、**PROに辿り着く前に離脱する人が増える**。無料の説得力が、
そのままPROへの入口になっている。

代わりに、**同じデータの深掘りをPRO側に置く**のが筋が通る。取り上げるのでは
なく、足す。

| 無料（いまのまま） | PROで足す |
|---|---|
| 町名の土地成約の坪単価分布 | **条件を揃えた分布**（幅員6m以上・整形地・同規模だけ） |
| 私道率・不整形率（近隣の傾向） | 対象地そのものの条件との突き合わせ |
| 延床の上限 | 斜線・絶対高さを入れた、実際に建つ形 |
| セットバックの概算 | 測量図の実測値 |

条件を揃えた分布は、無料版のばらつき±24%が±10%台まで下がる見込み。
これは「同じ数字をもう一度見せる」のではなく、**精度が上がっている**。

### ただし1つだけ、無料に足したい項目がある

**建築条件付きかどうか。**

注文住宅を探している人にとって、建築条件付きの土地は「注文住宅の土地では
ない」。ここを知らずに診断を受けても意味がない。選択肢1つ、減点なしの
注意表示だけでいいので、**無料側に置くべき**だと思う。
PROに隠すと、無料診断がその人にとって嘘になる。

## 7. 決めていないこと

### 費用のレンジは出さない（2026-09-16 に調べて決めた）

地盤改良の費用について、**公的な統計は無い**。探した範囲は次のとおり。

| 探したもの | 結果 |
|---|---|
| 国土交通省 建築工事費調査 | 工事実施額は取れるが、地盤改良の内訳は無い |
| 国土交通省 住宅市場動向調査 | 資金調達の調査。工事費の内訳は無い |
| 住宅金融支援機構 フラット35利用者調査 | 建設費・土地取得費まで。地盤改良の別掲は無い |
| e-Stat | 地盤改良費の統計は見つからない |

世の中で流通している「表層改良30〜80万円／柱状改良50〜150万円／鋼管杭
100〜200万円」という数字は、**すべて工務店や比較サイトが自社の見積りから
書いたもの**で、一次情報ではない。このサイトの基準では画面に出せない。

**したがって、費用のレンジは出さない。** 代わりに出すのは、

- 地盤調査を実施したか／改良が要ると出ているか（事実）
- 実施していないなら「金額はまだ誰にも分からない」と書く
- 近隣の地盤情報の見方（国土交通省 KuniJiban にボーリングデータがあるが、
  河川周りが中心なので、当たらない土地のほうが多い）

解体費・引き込み費も同じ扱いにする。一次情報が見つかったら、そのときに
出典つきで足す。

### その他

- **PROの価格を土地で変えるか。** 戸建・マンションと同じでよいかは未検討。
- **真北方向をどう聞くか。** 測量図がないと答えられない。回答率が低いなら
  斜線の計算は「可能性の指摘」に留める。
