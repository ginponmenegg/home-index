# 記事の予定

書くときの約束は `src/guides.py` の冒頭にある。ここに置くのは
**次に何を書くか**と、**書いてはいけないもの**だけ。

## 手順

1. **条文・出典を先に確かめる。** 記憶で書かない。法令は e-Gov の
   法令API（`https://laws.e-gov.go.jp/api/1/lawdata/{lawId}`）が全文を
   XMLで返す。ウェブ版はJavaScriptで描くので読めない
2. **コードが何をしているかを読む。** 記事は診断の中身の説明であって、
   一般論ではない。コードが使っていない数字は書かない
3. `src/guides.py` に `Guide(...)` を足し、`GUIDES` の先頭に入れる
4. **OG画像を焼く。** `python -c "import sys;sys.path.insert(0,'tools');
   import make_images as m;m.build_guides()"`
5. `pytest` を通す。目次・サイトマップ・記事間リンク・構造化データは
   自動なので、触らなくてよい

テストが規約を強制している（説明文60〜160字、見出しと目次の一致、
本文にidを書かない、リンク先が実在すること、OG画像が題名と一致すること）。
**通らないときは記事のほうが規約に反している。**

## 宿題（記事を書いていて見つかったもの）

**誘導居住面積水準の出どころが、令和3年の計画になっている。**
令和8年3月27日に新しい住生活基本計画（全国計画）が閣議決定され、
誘導居住面積水準と最低居住面積水準の**別紙が無くなった**。数値そのものは
一般観測指標（子育て世帯の誘導居住面積水準達成率42％、最低居住面積水準
未満率3.8％、どちらも令和5年）として残っているので、物差しとしては
使える。ただし結果画面は「4人世帯の誘導水準 125㎡」とだけ出していて、
どの計画の数字かを書いていない。**前提を隠さない**という決まりに照らすと、
ここは直すべき。記事（`yudo-kyoju-menseki-suijun`）には書いた。

**子どもの年齢による人数の換算を実装していない。**
3歳未満0.25人・3歳以上6歳未満0.5人・6歳以上10歳未満0.75人（2人未満の
ときは2人）。世帯人数しか聞いていないので、小さい子のいる家庭には実際より
厳しい水準を当てている。甘いほうに外すよりましなので急がないが、
外していることは記事に書いた。

## 記事の狙い（2026-10-01に決めたこと）

条文や数値が答えになる狭い記事（軽量鉄骨の厚み、角地の指定、建築条件の
3か月）は、**AEOには効くがSEOでは量が取れない**。検索している人が打つ
言葉と違うため。これらは引用される資産として残すが、順位は期待しない。

取りにいくのは**買う人が実際に打つ言葉**のほう。

    中古住宅 買ってはいけない 特徴
    内見 チェックリスト 中古戸建
    重要事項説明書 どこを見る
    不動産屋に 聞くこと リスト
    中古マンション 管理費 高い 判断

**PROの中身を無料で公開してよい**（2026-10-01に判断）。具体性が伝わらないと
月1,980円の価値が想像できないため、公開したほうが売れるという読み。
`disclosure.py` と `pro_scoring.AGENT_QUESTIONS` は記事にしてよい。

## 条文を引けないときの約束

e-Gov がメンテナンス中で引けないことがある。そのとき**条番号を記憶で
書かない。**2026-10-01、売買契約の記事で宅建業法37条・39条を引こうとして
e-Gov が落ちていたので、**条番号を書かずに内容だけ書いた**（手付解除は
「契約書の条項で確かめてください」とした）。リポジトリで確認済みなのは
35条とその号、都市計画法34条、建築基準法42・43・52・53・55・56条。
2026-10-08 に、宅建業法33・34条の2・36〜41条の2・78条、同施行令3条の5、
同施行規則15条の7・15条の8・16条の2の2・16条の2の3・16条の4の3、
民法557・562〜566・572条、水防法14条、品確法2・94・95条、
消費者契約法2・8条を引いて記事にした。

e-Gov の法令IDに注意。**宅建業法は `327AC1000000176`**（議員立法なので
AC1）。`327AC0000000176` では0件が返る。民法は `129AC0000000089`、
宅建業法施行規則は `332M50004000012`、同施行令は `339CO0000000383`。

## 書かないもの

**推定価格の根拠。** `neighbor_radius_m`、`k_nearest`、`reno_premium` は
題材として面白いが、鑑定評価の法的な整理が済むまで書かない。
`src/guides.py` の冒頭に同じことが書いてある。

**市区町村ごとの量産。** 地名だけ差し替えたページを1,741市区町村ぶん
作るのは、Googleの「スケーラブルなコンテンツの不正使用」にあたる。
罰は記事単位ではなく**ドメイン全体**に及ぶので、これまでの記事も
まとめて失う。

地域の記事を書くなら、**実際に商圏にしている数市に絞り、その市の実データを
APIから引いて、中身が本当に違うものを手で仕上げる**こと。それは量産ではない。
なお「〇〇市のハザードマップ」で市の公式サイトと競うのは筋が悪い。
市のサイトが1位であるべきだし、実際そうなる。差が出るのは
「その数字が、家を買う判断にどう効くか」のほう。

## 過去に間違えたこと

- **住宅ローン控除の床面積の下限が40㎡になっていた。** 中古住宅は50㎡以上
  （国税庁 No.1214）。40〜50㎡は取得時期に条件のある特例で、既定にすると
  使えない控除を「使える」と見せる。記事を書く前に出典を引いて気づいた
- **用途地域を「12種類」と書きかけた。** 平成30年4月1日に田園住居地域が
  加わって13種類になっている。古い資料は12種類のまま。条文を引いて助かった
- **予定表で土砂の記事の根拠を XKT021/022 と書いていた。** イエロー／レッドは
  XKT029。021は地すべり防止地区、022は急傾斜地崩壊危険区域で、根拠の法律も
  別。書く前にコードを読んで気づいた
