# 投稿の予定（X・Threads）

記事の予定は `docs/記事の予定.md`。ここに置くのは**SNSに何を出すか**と、
**出す順番**。

## 順番の決め方

**フォロワーが少ないうちは、広い話から出す。** 内容が正しくても、
読み手が「いま特定の条件に当てはまっている人」だけだと、そもそも
誰にも届かない。母数の大きい話を先に出して、読む人が付いてから
細かい話に降りる。

広さの目安：

| 広い | 狭い |
|---|---|
| すでに家に住んでいる人が自分の家で確かめられる | いま特定の条件の物件を検討中の人だけ |
| 3分でできて、何も買わなくていい | 書類を取り寄せる必要がある |
| 季節やニュースで効く | いつ出しても同じ |

## 書き方の約束

- **広告にしない。** サービス名も機能も本文に書かない
- **本文にリンクを入れない。** Xはリンクがあると表示が伸びにくい。
  記事へのリンクは**リプライ（スレッドの2件目）**に置く。本文を読んだ人
  だけがリンクを見る順番になる
- **数字はコードと記事から取る。** SNSだけの数字を作らない
- 文字数：X は140字、Threads は500字まで

## 取ってあるもの

### 住宅ローン控除の50㎡は、登記簿の面積で判定される

**いつ出すか：** 中古マンションを検討している人が読み手に混じってきてから。
2026-09-07に一度書いたが、**フォロワーが少ない段階では読み手が狭すぎる**
と判断して保留にした。

記事：`jutaku-loan-koujo-1982`

**X（140字）**

```
住宅ローン控除の「50㎡以上」は、登記簿の面積で判定されます。

マンションの登記簿は内法（壁の内側）。販売図面の専有面積は壁芯なので、図面で52㎡でも登記簿では50㎡を割ることがあります。

50㎡前後の部屋を見ているなら、契約前に登記事項証明書を取ってください。
```

**Threads（473字）**

```
仲介をしていて、いちばん「もっと早く言ってほしかった」と言われるのがこれです。

住宅ローン控除の「床面積50㎡以上」という要件は、登記事項証明書に書かれた面積で判定されます。

マンションの登記簿は内法（壁の内側）で測ります。一方、販売図面やチラシに載っている専有面積は壁芯（壁の中心線）。同じ部屋でも数㎡ちがいます。

図面で52㎡だから大丈夫だと思っていた部屋が、登記簿では49.8㎡だった、ということが起こります。「その他住宅」の区分なら、控除が使えるかどうかで10年間の合計が最大140万円変わります。

50㎡前後を検討しているなら、契約前に登記事項証明書を取ってください。数百円です。

もうひとつ。「築20年を超えると控除は使えない」は、いまは当てはまりません。築年数の要件は撤廃されていて、登記簿の建築日付が1982年1月1日以後かどうかで分かれます。それより前の建物でも、耐震基準適合証明書・建設住宅性能評価書の写し・既存住宅売買瑕疵担保付保険証明書のどれか1つがあれば対象になります。3つあることは、あまり知られていません。
```

## 出さないもの

**キャンペーンの価格を本文に書かない。** 期限が来たら消す手間が残り、
消し忘れると古い価格が残る。価格の話は固定ポストに置く。

**「〇〇の方へ」で始めない。** 対象を宣言した時点で、それ以外の人が
読まなくなる。事実から入って、当てはまる人が自分で気づく形にする。
